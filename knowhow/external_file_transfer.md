# 外部檔案傳輸

## 用途

定位外部檔案接收、傳送、格式驗證與日常監控的 SOP。

## 常見問法

- 外部檔案傳輸失敗要看哪裡？
- 檔案沒收到怎麼查？
- SFTP 傳輸規格在哪？
- 外部介接每日要檢查什麼？

## 常見技術詞

外部檔案、file transfer、SFTP、FTP、inbound、outbound、格式驗證、介接。

## 原始資料位置

- Word：`U:/Company/SOP/ExternalFile/FILE_TRANSFER_OPERATIONS.docx`
- Folder：`U:/Company/SPEC/ExternalFile/`
- Java Folder：`D:/workspace/file-transfer/`

## 下一步

請用 Copilot Chat 開啟 SOP，並依檔案名稱、批次時間與傳輸 log 確認問題位置。

## 關鍵結論

- 先分辨是來源未產檔、傳輸失敗或接收端驗證失敗。
- 不要在未確認重複風險前手動重送。
